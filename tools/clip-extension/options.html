🔗 连接设置

clip-server.py 的监听地址
服务端启用了鉴权时（启动日志会打印「鉴权: 已启用」），这里必须填 与 tools/config.local.json 中 token 完全一致的字符串，否则所有请求都会返回 401 unauthorized。
服务端已启用鉴权，我该填什么？
  1. 先看 tools/config.local.json 是否已经存在：
    • 已存在 → 直接打开它，复制 token 字段引号内的那串值
    • 不存在 → 把 tools/config.example.json 复制一份改名为 config.local.json （cp / copy），再把 token 改成自己的随机串
  2. 把同一串 token 粘贴到上方输入框，点「测试连接」
  3. 改 config.local.json 里的 token 后要重启 clip-server.py 才生效；只改本插件不需要重启

⚠️ 不要覆盖已存在的 config.local.json —— 那会用示例文件里的 token 替换掉你本机的 token，服务端与插件就对不上了。

生成新 token：python3 -c "import secrets; print(secrets.token_urlsafe(32))"； 或用环境变量 CLIP_SERVER_TOKEN 启动服务，效果相同。

本机自用、不想配 token？ 把 config.local.json 的 token 改成空字符串 "" 并重启服务 —— 服务端检测到空 token 会自动跳过鉴权， 这里留空即可。代价：同一台机器上的其他程序也能调用这个接口。
